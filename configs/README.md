# Historical configurations

These YAML files reproduce the exploratory workflow in `run_train.py` and
`run_all.py`. Their names, including `deployable.yaml`, predate the revised
nested validation. They do not define the September or November results.

Use `run_nested_validation.py` for the reference analysis and the scripts linked
in the [repository README](../README.md) for the review additions. The revised
analysis rebuilds CPT-only stress variables and uses 300 trees. Historical
500/700-tree models and their preprocessing must remain together.
